# TTS 配置改为 preset

日期：2026-07-05

## 背景

TTS 原先按 provider 分散保存配置，运行时选择的是 provider/model 组合。现在改为 preset 概念：运行时只保存并使用一个 active preset，每个 preset 自己声明 provider 和该 provider 运行所需的配置。

## 变更内容

- `config/plugin/tts/config.json` 改为保存全局设置：
  - `activePresetName`
  - `editPresetName`
  - `translationPresetName`
  - `translationPresets`
- 每个 TTS preset 独立保存为 `config/plugin/tts/presets/<preset>.json`。
- `mimo`、`bailian`、`openai-api` 分别迁移为同名 preset。
- Genie 按旧模型配置生成多个 `genie-*` preset。
- Genie preset 保存运行所需的 model/reference 指针：
  - `modelDir` 保存在 preset JSON。
  - reference audio/text 从 `assets/tts/preset/<preset>/reference.*` 和 `reference.txt` 推断，不写入 JSON。
- 管理后台 TTS 配置、上传路径、测试接口、schema 和前端表单改为读写 preset 结构。
- 运行时不再读取 `config/plugin/tts/providers/*.json` 作为配置来源。

## 迁移

本地配置已通过一次性迁移处理，没有把迁移代码加入代码库。

迁移后：

- active preset 为 `mimo`。
- 旧 provider 配置迁移为对应 preset。
- 旧 Genie reference audio/text 移到各自 `genie-*` preset 资源目录。
- 旧 Genie model 目录保留为 model 指针目标，reference 与 model 解耦。

## 兼容性

- 这是配置结构变更，不保留旧 provider 配置 fallback。
- preset 文件名使用扁平结构，避免 `:` 等字符影响文件名。
- reference audio/text 仍然彼此绑定，但不再和 Genie model 绑定。
- 管理后台返回的 public config 会隐藏密钥，并只暴露当前 preset 的可编辑视图。
